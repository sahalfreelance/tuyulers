[{"wallet":"0x...","qty":2,"tier":"wl"},{"wallet":"0x...","qty":1,"tier":"gtd"}]

Google Form — Auto Detect entry.xxx

Paste URL Google Form → Auto Detect. Tool akan fetch form via CORS proxy, parse entry.123 + label pertanyaannya. Kalau proxy diblok, pakai Bookmarklet di tab Sniffer.

Trial lu terdeteksi: PixelRebelhoods Whitelist — 4 field:
• Follow @pixelrebelhoods — entry.839997441 (Yes/No)
• Like and RT pinned post — entry.1454126146 (Yes/No)
• Why do you want to join the Rebels? — entry.375113864 (paragraph)
• Comment wallet address — entry.1564133707 (short answer)

Auto Detect — Sniffer (Google Form + API)

Website di GitHub Pages tidak bisa akses DOM / network tab lain karena CORS. Sniffer jalan di halaman target itu sendiri via bookmarklet:

  1. Drag link di bawah ke Bookmark Bar
  2. Buka halaman form/API target (Google Form atau owlarc.xyz)
  3. Klik bookmark → auto scan entry.xxx + hook fetch/XHR
  4. Submit form sekali → sniffer akan log URL + payload lengkap → copy ke tab API
🔍 WL Detect ✍️ WL AutoFill 









Kenapa tidak 100% auto dari website?



• Google Form: docs.google.com tidak kasih header Access-Control-Allow-Origin. Fetch langsung dari GitHub Pages diblok browser. Solusi: via CORS proxy (AllOrigins) atau bookmarklet. Tool ini coba proxy dulu otomatis.

• Custom API: tiap web beda endpoint/header/auth. Tidak ada cara “scan internet” — harus lihat network tab saat submit. Sniffer di atas hook fetch + XMLHttpRequest + form submit, jadi apapun API-nya kelog.
